Bienvenida

Ingeniería de Requisitos es la materia en la que vas a aprender a relevar, analizar y documentar los requisitos de un sistema antes de construirlo: identificar stakeholders, elicitar información y describirla con precisión usando casos de uso, LEL y escenarios.

El Campus Virtual es el canal oficial de la materia: ahí se gestionan las entregas, los trabajos prácticos y las actividades de la cursada. Esta página web es un complemento para cuestiones administrativas y de organización (cronograma, accesos rápidos, programa, etc.).

¿Qué vas a aprender?

  • Analizar un proceso de negocio
  • Identificar stakeholders
  • Elicitar requisitos utilizando distintas técnicas
  • Diferenciar requisitos funcionales y no funcionales
  • Documentar requisitos mediante distintas herramientas
  • Justificar decisiones de análisis
  • Mantener trazabilidad durante el proyecto
